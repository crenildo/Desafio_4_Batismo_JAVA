Este projeto demonstra conceitos fundamentais da Programação Orientada a Objetos (POO) em Java, aplicados em um cenário inspirado no universo ninja. A solução utiliza herança, polimorfismo, interfaces, construtores e enumerações para modelar diferentes tipos de personagens e suas habilidades.

A interface Ninja1 define o comportamento base comum a todos os ninjas. As classes NinjaBasico e NinjaAvancado implementam essa interface, cada uma expandindo ou especializando funcionalidades conforme seu nível. O enum TipoHabilidade organiza os tipos de habilidades possíveis, garantindo maior clareza e segurança no código.

O objetivo do projeto é servir como um exemplo simples e organizado de como aplicar os pilares da POO em casos práticos e de fácil entendimento.
