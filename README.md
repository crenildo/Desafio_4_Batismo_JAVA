# Desafio 4 - Batismo de JAVA

## 🔎 Sobre este projeto  
Projeto em Java para demonstrar conceitos de Programação Orientada a Objetos (POO): herança, polimorfismo, interfaces, enums e construtores. Cria personagens “ninjas” com diferentes tipos de habilidade.

## 🎯 Objetivo  
Servir como exemplo didático para entender e aplicar os pilares da POO de forma clara, modular e organizada — ideal para quem está estudando Java ou preparando portfólio.

## 🧱 Estrutura do Código  
- `Ninja1` (interface): define os métodos básicos de todo ninja.  
- `NinjaBasico`: implementação simples com nome, idade e tipo de habilidade.  
- `NinjaAvancado`: extensão da interface com habilidade especial adicional.  
- `TipoHabilidade` (enum): define os tipos possíveis de habilidades.  

## 🚀 Como executar  
1. Clone o repositório  
2. Abra em sua IDE favorita (IntelliJ, Eclipse, VS Code…)  
3. Compile e execute a classe `Desafio4.java` (ou `Main.java`)  
4. Veja o resultado no console — nomes, idade e habilidades de cada ninja  

## ✅ Conceitos Demonstrados  
- Herança / Polimorfismo  
- Interface como contrato  
- Uso de enums para organizar constantes  
- Construtores e inicialização de objetos  
- Implementação de diferentes “níveis” de objetos  

## 📚 Para que serve  
- Estudo e prática de POO em Java  
- Base para evoluir o projeto — adicionar novos tipos, habilidades, lógica de combate, etc.  
- Exemplo de código organizado para portfólio pessoal
